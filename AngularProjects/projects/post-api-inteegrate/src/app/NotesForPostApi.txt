POST API and POST API Integration in Angular 22
Let's learn this step by step using your Angular Product Management project and JSON Server.
1. What is a POST API?
A POST API is an API endpoint that accepts data from a client and typically creates a new record on the server.

For example, suppose your Angular application has a form to add a new product:
- Product name: Headphones
- Price: 2000
- Category: Electronics
When you click Add Product, Angular sends this data to the backend using an HTTP POST request. The server creates the product and returns a response.

Step 1: Prepare your JSON Server
In your project's db.json, make sure you have a products array.
{
  "products": [
    {
      "id": "1",
      "name": "Laptop",
      "price": 55000,
      "category": "Electronics"
    }
  ]
}


Start JSON Server in your terminal:
npx json-server db.json


Your POST endpoint is:

http://localhost:3000/products
Step 2: Create the Product interface
Create src/app/models/product.ts.
export interface Product {
  id: string;
  name: string;
  price: number;
  category: string;
}


The interface defines the expected structure of a product.

When adding a product, you don't need to provide an ID in this example; JSON Server generates one automatically.
Step 3: Configure HttpClient
In app.config.ts, add provideHttpClient() to the existing providers:
import { ApplicationConfig } from '@angular/core';
import { provideHttpClient } from '@angular/common/http';

export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient()
  ]
};


If you already have providers, keep them and add provideHttpClient().
Step 4: Write the POST API in your service
Generate the service if you haven't already:
ng g s services/product


In services/product.ts, add the following code. Keep the service decorator generated by your Angular CLI; the example below uses @Injectable().
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Product } from '../models/product';

@Injectable({
  providedIn: 'root'
})
export class ProductService {
  private http = inject(HttpClient);

  private apiUrl = 'http://localhost:3000/products';

  addProduct(product: Omit<Product, 'id'>) {
    return this.http.post<Product>(
      this.apiUrl,
      product
    );
  }
}


Understand the POST method
return this.http.post<Product>(this.apiUrl, product);


- http.post() sends a POST request.
- this.apiUrl is the API endpoint.
- product is the data sent in the request body.
- <Product> specifies the expected response type.
For example, Angular sends this JSON body:
{
  "name": "Headphones",
  "price": 2000,
  "category": "Electronics"
}


JSON Server creates the record and returns the saved product, including its generated ID.
Step 5: Create the product form in your component
Open app.ts and add this code:
import { Component, inject } from '@angular/core';
import { FormsModule } from '@angular/forms';
import { ProductService } from './services/product';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [FormsModule],
  templateUrl: './app.html'
})
export class App {
  private productService = inject(ProductService);

  name = '';
  price: number | null = null;
  category = '';

  message = '';

  addProduct() {
    if (
      !this.name.trim() ||
      this.price === null ||
      this.price <= 0 ||
      !this.category.trim()
    ) {
      this.message = 'Please enter valid product details.';
      return;
    }

    const newProduct = {
      name: this.name.trim(),
      price: this.price,
      category: this.category.trim()
    };

    this.productService.addProduct(newProduct).subscribe({
      next: (response) => {
        this.message = `Product ${response.name} added successfully!`;

        this.name = '';
        this.price = null;
        this.category = '';
      },
      error: (error) => {
        console.error('POST API failed:', error);
        this.message = 'Failed to add product.';
      }
    });
  }
}


Why do we use subscribe()?

The HTTP request is asynchronous. subscribe() lets us handle the response when the server successfully creates the product, or handle an error if the request fails.
Step 6: Create the HTML form
Open app.html:
<h2>Add New Product</h2>

<form (ngSubmit)="addProduct()">
  <div>
    <label>Product Name</label>
    <input
      type="text"
      name="name"
      [(ngModel)]="name"
      required
    />
  </div>

  <div>
    <label>Price</label>
    <input
      type="number"
      name="price"
      [(ngModel)]="price"
      min="1"
      required
    />
  </div>

  <div>
    <label>Category</label>
    <input
      type="text"
      name="category"
      [(ngModel)]="category"
      required
    />
  </div>

  <button type="submit">Add Product</button>
</form>

<p>{{ message }}</p>


Here:
- FormsModule enables template-driven forms and ngModel.
- [(ngModel)] connects each input to its component property.
- (ngSubmit) calls addProduct() when the form is submitted.
- The component sends the data to the service, which calls the POST API.

Remember the POST API flow
1. User enters product details in the form.
2. The component collects the data.
3. The component calls ProductService.addProduct().
4. HttpClient.post() sends the data to JSON Server.
5. JSON Server saves the new record and returns a response.
6. The component displays success or error feedback.
